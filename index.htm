Tujuan Pembelajaran (Deep Learning)

Siswa dapat menganalisis karakteristik fungsi eksponen $f(x) = a \cdot b^{x-c} + d$, mengidentifikasi pengaruh perubahan parameter terhadap bentuk grafik, serta memahami landasan konsep pertumbuhan dan peluruhan eksponensial.

Transformasi Parameter

Bentuk Umum Fungsi

$f(x) = 1 \cdot (2)^x + 0$

Nilai Awal ($a$): 1 Skala vertikal
Basis / Factor ($b$): 2 Pertumbuhan ($b>1$)
Geser Horizontal ($c$): 0 Kanan / Kiri
Geser Vertikal / Asimtot ($d$): 0 Atas / Bawah

Observasi Penting:

  • Garis putus-putus merah merepresentasikan **Asimtot Datar** $y = d$.
  • Jika basis $b > 1$, grafik **naik pesat** (Pertumbuhan).
  • Jika $0 < b < 1$, grafik **turun mendekati asimtot** (Peluruhan).

Deep Learning Insight: "Mengapa Eksponen Begitu Dahsyat?"

Fungsi **Linear** bertambah secara konstan (penjumlahan konstan), sedangkan Fungsi **Eksponensial** bertambah secara multiplikatif (perkalian berulang). Dalam jangka panjang, pertumbuhan eksponensial **selalu melampaui** pertumbuhan linear.
